## About

SimplyNotifier is a simple plugin for Paper/Purpur servers running on 26.2+ that allow players to be notified when someone says their name in the in-game chat. This project is in it's early stages at the moment, but updates will come with more features. 

## Planned Features

We plan to add
- Notification disabling through a command
- Notification message editing through config
- Notification sound editing through config
